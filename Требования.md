ТЗ: D&D Character Companion — универсальный лист персонажа D&D 5e 2014
Создай полноценное браузерное приложение для ведения персонажа в D&D 5e по правилам 2014 года.
Это не просто красивый character sheet. Приложение должно быть интерактивным помощником игрока, который автоматически считает игровые параметры, отслеживает ресурсы и помогает понимать, что можно делать во время своего хода.
1. Главные требования
Приложение должно:
• работать в браузере;
• корректно работать как на ПК, так и на телефоне;
• иметь адаптивный интерфейс;
• работать без сервера и регистрации;
• сохранять данные персонажа в LocalStorage браузера;
• автоматически пересчитывать связанные параметры;
• объяснять пользователю, откуда взялось каждое рассчитанное значение;
• использовать исключительно правила D&D 5e 2014 года;
• не использовать правила D&D 2024;
• не придумывать игровые правила самостоятельно;
• если какая-либо механика не определена в имеющихся данных — явно обозначать это, а не выдумывать правило.
Интерфейс приложения должен быть на русском языке.
Расстояния отображать в метрах, а не в футах.
Кубики приложение НЕ бросает. Пользователь физически бросает кубики сам.
История бросков не нужна.
Анимации не нужны.

Стиль:
• dark fantasy;
• немного готики;
• современный UI;
• минималистично;

• хорошая читаемость;

• не превращать приложение в декоративный сайт.
Главный приоритет — удобство использования во время игры.
На телефоне все основные кнопки должны быть удобно нажимаемыми пальцем.
Не использовать огромное количество мелких элементов.

7. Объяснение расчетов
Это одна из ключевых функций приложения.
Каждое сложное автоматически рассчитанное значение должно иметь возможность показать пользователю подробное объяснение.
Например:
DC спасброска заклинаний: 15
Нажатие на значение открывает:
8 + бонус мастерства + модификатор WIS
8 + 3 + 4 = 15
Другой пример:
Бонус атаки заклинанием: +7
бонус мастерства + модификатор WIS
+3 + +4 = +7
Объяснения должны быть понятными человеку, который еще не идеально знает правила D&D.

Темная основа.
Готические элементы использовать умеренно.
Приложение должно выглядеть как современный качественный инструмент, а не как сайт из фэнтезийной MMORPG 2008 года.


⸻


38. Ошибки
Предотвращать невозможные действия.
Например:
• использовать отсутствующую ячейку;
• использовать ресурс, которого больше нет;
• потратить реакцию дважды;
• экипировать несовместимую вещь;
• выйти за допустимое значение, если правила это запрещают.
Для потенциально опасных действий использовать подтверждение.


⸻


39. Объяснение механик
В приложении должна быть система подсказок.
Если пользователь нажимает на:
«Атака»
показывать объяснение.
Если нажимает на:
«Концентрация»
показывать объяснение.
Если нажимает:
«Бонусное действие»
показывать, что это означает.
Цель — чтобы приложение постепенно помогало игроку выучить D&D, а не просто считало цифры за него.


⸻

# Помощник персонажа D&D

Браузерное приложение для ведения персонажа D&D 5e 2014.

## Запуск

Локально проект запускается только через Docker.

```bash
docker compose up --build -d
```

Открой в браузере: http://localhost:8080

Остановка:

```bash
docker compose down
```

## Публичный адрес (GitHub Pages)

Приложение можно открыть с любого устройства без домашней сети. Это статическая страница: сервера с аккаунтами нет, персонаж хранится в браузере на этом устройстве.

После создания репозитория:

1. Залейте проект в ветку `main`.
2. В Settings - Pages выберите Source: GitHub Actions.
3. Дождитесь workflow "Deploy to GitHub Pages".
4. Откройте `https://ВАШ-АККАУНТ.github.io/dnd-panel/`.

Сохранения привязаны к адресу сайта. Данные с localhost или с домашнего IP на публичный адрес сами не переедут. Чтобы перенести персонажа, используйте экспорт и импорт файла.

Требования к продукту: `Требования.md`. Техническое описание реализации: `Техническое задание.md`.

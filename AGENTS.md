# Инструкции для агента

Файл `Требования.md` - главные требования к проекту. Это источник правды по продукту, правилам D&D 5e 2014 и поведению приложения.

Не изменяй `Требования.md`. Не переписывай, не сокращай, не дополняй и не "уточняй" его содержимое, даже если кажется, что так будет аккуратнее или полнее.

При реализации, рефакторинге и ответах следуй `Требования.md` как есть. Если задача противоречит требованиям, сообщи об этом и не меняй сам файл требований.

Локально запускай проект только через Docker Compose. Не используй `npm run dev` и другие запуски на хосте.

```bash
docker compose up --build -d
```

Адрес: [http://localhost:8080](http://localhost:8080)
